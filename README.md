## The entry

> doohickey

9 characters, one word. It's the word for things we cannot name — delete it, and the fallback word for unnamed things is itself gone.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
